プライバシーポリシー

Shirabeコードで、どんな情報をどう扱うかを書きます。コード進行を組み立てて見るだけなら、ログインは要らず、入力した内容は送りません。譜面を共有するときは、次のとおり扱います。

ログインで受け取るもの

ログインは Google だけです。Google から受け取るのは openid だけで、メールアドレスや名前は受け取らず、持ちません。

ログインの管理には AWS の Cognito を使います。Cognito のユーザーには、Google の識別子（ユーザー名）と、Cognito が発行する sub が残ります。共有をすべて削除しても、Cognito のユーザーの記録は残ります。消す手段は用意していません。

共有で保存するもの

  • 譜面（各コードと押さえ方、カポ）
  • タイトル、ひと言、表示名（共有のたびに本人が入力した文字）
  • 作成日時
  • 持ち主の識別子（Cognito の sub）

共有した譜面は、URL を知る人は誰でも見られます。本人が /mine から削除するまで残ります。

ログ

CloudFront と API Gateway のアクセスログは取っていません。Lambda のログには、エラーの種類など入力を含まない固定の記録だけが残り、30 日で消えます。

AWS・Google・Cloudflare は、それぞれの方針で、通信元の IP アドレスなどを記録することがあります。

ブラウザの中

ログインのトークンと、入力途中の譜面を、ブラウザの sessionStorage に置きます。タブを閉じると消えます。

使う外部のサービス

  • Google のログイン
  • Cloudflare Turnstile（不正な書き込みを防ぐための確認。共有のダイアログを開いたときだけ読み込みます）
  • AWS（サイトの配信、ログイン、共有の保存）
