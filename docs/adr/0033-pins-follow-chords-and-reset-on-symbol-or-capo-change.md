# 0033. 画面で押さえ方を固定できるコードを全部に広げ、固定は記号の変更とカポの変更で外す

- **Status**: Active
- **Date**: 2026-11-07

## Context

[0022](0022-score-first-layout-with-collapsible-editor-panel.md) は、押さえ方を選べるのを最初のコードだけにし、手の位置のボタンをそこへの入口にした。[0028](0028-capo-as-transposition.md) は、カポを変えたら最初のコードの固定を外すとした。コアは [0032](0032-pin-any-chord-with-a-single-hand-window.md) で任意のコードの固定に対応したので、画面を合わせる。固定が複数になると、進行の編集（記号の変更・削除・カポ）で固定をどう扱うかを決める必要がある。

## Decision

0022 と 0028 は supersede せず、次の項目だけを改める（0024・0032 と同じ扱い）。

- 「押さえ方」タブは、選んでいるコードに候補があれば、どのコードでも出す。固定は進行の位置ごとに持ち（`pins`）、コアにそのまま渡す。固定したコードのカードに「固定」の印を付ける（印刷には出し、コピーのテキストには出さない）。
- 固定は、固定したコードに付く。コードの記号が変わったら、その位置の固定を外す（固定した形は前の記号に対するものだから）。コードを削除したら、そのコードの固定は消え、後ろの固定の位置を 1 つ詰める。追加は末尾だけなので、位置は動かない。コードの並べ替えは画面に無いので、コードごとの識別子（id）は足さない。
- カポを変えたら、すべての固定を外す（0028 の「最初のコード」を全体に広げる）。固定した形は前のカポの形の記号に対するもの。
- 手の位置のボタンは、今どおり常に出す。値は、固定のうち進行の先頭に最も近いものの最低フレット（コアの窓の基準。0032）で、固定が無ければ「おまかせ」。押すと、その固定のコード（無ければ 1 番目）を選んで「押さえ方」タブへ移る。移る先に候補が無いときだけ押せない。コピーのテキストの「手の位置：」の行も同じ値にする。

## Consequences

- カポを変えると、固定した形がすべて消える。カポごとに固定を持ち越す手間はないが、カポを試すたびにやり直しになる。
- 固定を保存・共有する仕組みは無い（M4 の領分）。

## Why not

- **カポを変えても、移調した形に固定を持ち越す**: 固定した形のフレットは同じでも、別の記号を鳴らす形になる。持ち越すと、人が選んだ形と別の物になり、合わない固定が残りうる。
- **記号が変わっても固定を残し、合わなければ失敗にする**: 失敗の文が出て、人が固定を直すまで譜面が出なくなる。外すほうが、ふだんの編集を止めない。
- **コードに id を持たせ、固定を id に付ける**: 画面に並べ替えが無く、位置を詰めるだけで固定は正しく付き続ける。並べ替えを足すときに考える。
- **削除したとき、後ろの固定も外す**: 固定したコードは残っているのに、人が選んだ形が理由なく消える。詰めれば、固定は固定したコードに付いたままでいられる。
