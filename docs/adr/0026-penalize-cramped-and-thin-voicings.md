# 0026. 窮屈な形と鳴る弦が少ない形は、コストで選びにくくする

- **Status**: Active
- **Date**: 2026-11-06

## Context

ギターに詳しい人のレビューで、おまかせに次の形が出ると指摘された。

- 窮屈な形: Bb の `x10331`、Bb7 の `x10131`。開放弦をはさんで同じフレットを別々の指で押さえ、指を 4 本使う。標準は `x13331`・`x13131` のセーハ。
- 薄い形: Eb の `xx10x3`。鳴る弦が 3 本だけ。

[0018](0018-minimize-voicing-cost-with-dynamic-programming.md)・[0024](0024-discount-open-strings-only-in-low-positions.md) のコストでは、`x10331` はセーハの加算を避けて開放弦の値引きを受け、`x13331` より約 1 安い（6.50 と 7.54）。`xx10x3` は指が 2 本で済む分だけ安く、`x68886` とほぼ同じ（8.50 と 8.54）。

## Decision

単体コスト（`scoreVoicing`）に 2 つの項を足す。重みは `CostWeights` に置く。

- 窮屈な形（`crampedShape`）に 1.5 を足す。次の 3 つを全て満たす形。
  - 最も低いフレットを押さえる弦が 2 本以上ある。
  - その弦の間に、開放弦と、より高いフレットを押さえる弦の両方がある。
  - 指が 4 本必要（`voicingFeatures` の `fingers` が 4）。
- 鳴る弦が 4 本（`MIN_COMFORTABLE_STRINGS`）に足りない形に、足りない 1 本ごとに 0.5 を足す（`missingSoundingStrings`）。
- 他の重みは変えない。生成する押さえ方の集合（[0017](0017-voicing-validity-conditions.md)）も変えない。

重みは、`Bb Eb F Bb` と `Fm7 Bb7 EbM7 AbM7` から 3 つの形が消え、標準形の進行（`C Am F G7`・`Dm7 G7 CM7`・`E A B7 E`・`F#m7 B7 EM7 C#7`）が変わらない範囲で試した。窮屈な形 1〜2 × 薄い形 0.3〜1 の組はどれも同じ結果になった。窮屈な形 1.5・薄い形 0.5 は、Issue で示された初期値。薄い形を 0 にすると、Bb が `x103x1` になり、Eb は `xx10x3` のまま残る。ミュートなど他の重みを動かす必要は無かった。

## Consequences

- おまかせの単体結果が変わる。12 のルート × 26 の種類では、次の 10 コードで、変更前の形はどれも窮屈な形。

  | コード | 変更前 | 変更後 |
  | --- | --- | --- |
  | FM7 | `102210` | `10x210` |
  | F6 | `100211` | `100x11` |
  | Fadd9 | `103011` | `10x011` |
  | Fdim | `12x101` | `1231x1` |
  | Fdim7 | `120101` | `1x0101` |
  | Faug | `10x221` | `10322x` |
  | Fsus2 | `1x3011` | `1330x3` |
  | F7(#11) | `101201` | `121211` |
  | F#aug | `2x0332` | `210x32` |
  | Abm7-5 | `420402` | `420102` |

- ベースも選べるスラッシュコード（候補のある 3719 通り）では、138 通りが変わる（窮屈な形をやめるもの 134、鳴る弦が少ない形をやめるもの 4）。例は `D/F#`（`200232` → `2002x2`）、`C/F`（`132010` → `1x2010`）、`Am/F`（`102210` → `10x210`）。やめた先が高い位置になるものもある（`Gm7/Ab` の `410031` → `453333`、`Eb9/Bb` の `x11021` → `643343`。鳴る弦が少ない形をやめる `Adim/Eb` も `xx121x` → `x675x5`）。規模と例を確かめて受け入れた。

- 進行は `Bb Eb F Bb` が `653336 x65343 133211 x13331`（変更前は `x10331 xx10x3 133211 x10331`）、`Fm7 Bb7 EbM7 AbM7` の Bb7 が `x13131`（変更前は `x10131`）になる。標準形の進行は変わらない。
- 窮屈な形は禁止でなくコストなので、他に候補が無いコードでは選ばれうる。
- 選択欄（`listShapesByLowestFret`）の代表も、同じコストで決まるので、同じ最低フレットにより安い形があれば、窮屈な形は代表から退く。

## Why not

- **妥当性の条件（0017）で窮屈な形・薄い形を除く**: 他に候補が無いコードで結果が 0 件になりうる。0017 は「弾ける形」の条件で、「選びたい形」はコストで決める分担を保つ。
- **ミュートの重みを上げて薄い形を避ける**: 2 を 3 にすると `Bb Eb F Bb` の最後の Bb が `x10331` のまま残る。4 にすると窮屈な形は消えるが、`Fm7 Bb7 EbM7 AbM7` は（3 の時点で）`131111 653334 x65333 465544` に変わり、標準形の Bb7 `x13131` が選ばれない。標準形の進行は変わらないが、窮屈な形だけを狙えず、ほかの結果まで動く。
- **セーハの加算を 0 にする**: `Bb Eb F Bb` の Bb が `x10331` のまま残る（差が約 1 あり、セーハの加算 0.5 を無くしても逆転しない）。
- **開放弦の値引きを下げる**: 0.25 にしても `x10331`・`xx10x3` は残る。開放弦を使う定番の押さえ方（`x32010` など）まで不利になる（0018・0024 の Why not と同じ）。
