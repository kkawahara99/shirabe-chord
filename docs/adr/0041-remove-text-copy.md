# 0041. 「テキストでコピー」をやめる

- **Status**: Active
- **Date**: 2026-11-11

## Context

譜面を渡す手段は、印刷（[0025](0025-select-review-findings-by-product-tradeoffs.md) の #50）に加えて、共有の URL（[0035](0035-share-by-unguessable-url-with-google-login.md)）ができた。押さえ方のテキストコピー（0025 の #50 のもう一方）は、図も指番号も落ちるので、渡す手段としては共有に劣る。画面のボタンも増えている。

## Decision

- 「テキストでコピー」のボタンと、押さえ方の一覧のテキストを作る処理（`progressionText`）を消す。手の位置の表示（`handPositionLabel`）は画面のボタンが使うので残す。
- 0025 の #50 は「印刷」だけを残す。0028 の「コピーのテキストにカポの情報を足す」、0033 の「コピーのテキストに『固定』を出さない」「コピーの『手の位置：』の行」は、対象が無くなったので効力を失う（0028・0033 のそのほかの決定は変えない）。旧 ADR は書き換えない。

## Consequences

- ログインしない人や、共有が設定されていない環境では、譜面を持ち出す手段が印刷だけになる。
- ボタンとテスト、クリップボードの扱いが減る。

## Why not

- **残す**: ログインなしで使える持ち出し手段としての価値はある。ただし主な用途は共有と印刷で、図のない一覧は渡す側の意図を伝えきれないとみた。必要になったら足し直す。
