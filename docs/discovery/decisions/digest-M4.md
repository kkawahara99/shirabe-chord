=== M4 譜面をURL限定で共有できるようにする 到達ダイジェスト ===

- 達成状態: 公開 URL で、Google でログイン → 共有 → URL をログインなしで開く → 一覧 → 削除 → 削除した URL は見られない、と 20 件の上限を、実環境で確かめた（#73〜#82）。Cognito のユーザーに残るのは `sub` と Google の識別子だけで、ログインは PKCE（S256）。ただし Google の同意画面は「テスト中」のままで、共有できるのはテストユーザーに足した人だけ（本番にするのは #94）。
- 判断の置き場所: 重い判断は ADR 0035・0036、軽微な判断は `decisions/` の #74〜#82。
- 履歴の再照合（`scan-history`）: 指摘あり（M2 から続く既知のもの。M3 の時点から増えていない）。
- 想定とずれうる点: 適用のたびに Google の IdP に偽の差分が出る（Cognito が自動で足す 6 項目。直すのは #95）。プライバシーポリシーには問い合わせ先を置かず、Cognito の記録は共有を消しても残ることを書くだけにする（本人の判断。#94）。
