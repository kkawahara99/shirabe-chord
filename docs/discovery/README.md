# discovery — 調査記録・軽微な自律判断ログ

雑多な作業記録と、後から直せる**軽微な**自律判断を残す。**設計の方向を決めた判断（Why / Why not）は ADR（[../adr/](../adr/)）が正本**で、ここには書かない。

`decisions/` は軽微な自律判断のログ（追記のみ）。`work-issue` が根拠なく決めた軽い選択を、Issue ごとのファイル `decisions/<Issue番号>.md` に、日付・Issue・決めたこと・根拠 / 代替案の 4 列の表で残す。重い判断は ADR へ。マイルストーン到達ダイジェストは `decisions/digest-M<n>.md`。Issue を経由しない作業の軽微な判断は、ここには書かず、コミット本文に書く。

Issue ごとのファイルにしたのは、並走する PR が同じ場所を直して衝突するのを避けるため。1 つの表に戻さない。

調査記録は発生都度 `yyyymmdd-<主題>.md` で追加する（例 `20261015-chord-voicing-survey.md`）。日付プレフィックスでいつの作業かが分かる。
